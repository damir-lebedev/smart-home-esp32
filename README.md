# Smart Home ESP32 Controller

Управление реле (свет, розетки и т.п.) в доме через Wi-Fi: у каждой комнаты — свой ESP32-модуль с реле, один из модулей работает мастером и показывает общую панель управления домом. Обновление прошивки на всех модулях — по воздуху, без USB.

## Возможности

- Управление реле по Wi-Fi: `/on`, `/off`, `/toggle`, состояние сохраняется при перезагрузке.
- Единая веб-панель на модуле-мастере со всеми комнатами сразу, живое обновление состояния через WebSocket.
- Автообнаружение модулей в локальной сети (slave объявляет о себе по UDP, master их подхватывает).
- **Обновление прошивки по воздуху**:
  - на любом отдельном модуле — через встроенный веб-портал `http://<ip>/update` (ElegantOTA);
  - на **всей сети сразу** — с панели мастера: загружаете `.bin` один раз, жмёте «Обновить всю сеть», мастер по очереди раздаёт прошивку всем известным модулям и ждёт, пока каждый перезагрузится на новой версии, прежде чем перейти к следующему.
- Удалённая настройка (`/config`): смена имени комнаты, роли (master/slave) и ключа без переподключения по USB.
- Автовосстановление: аппаратный watchdog перезагружает модуль, если прошивка зависла, а при потере Wi-Fi модуль сам пытается переподключиться и в крайнем случае перезагружается — не нужно вручную обесточивать реле, если оно «отвалилось».

## Аппаратная часть

- ESP32-C3 (проект настроен под Adafruit QT Py ESP32-C3 / esp32-c3-m1i-kit, 4MB флеша — для OTA важно, чтобы плата поддерживала OTA-разделы, см. `platformio.ini`)
- Реле-модуль 250VAC (переключение нагрузки), пин задан в `src/globals.cpp` (`RELAY_PIN`)

RGB-лента, MQTT и голосовое управление, упомянутые в более ранних версиях этого README — в текущем коде не реализованы, это только идеи на будущее.

## Как запустить

1. Установить PlatformIO (расширение VS Code) или использовать `pio` из командной строки.
2. `pio run -t upload` — прошить модуль по USB (нужно один раз на каждый физический модуль; дальше все обновления уже можно накатывать по Wi-Fi).
3. Модуль поднимает точку доступа `SmartModule_Setup` — подключаемся к ней с телефона/компьютера.
4. Открываем `http://192.168.4.1`, вводим Wi-Fi (**обязательно 2.4 ГГц** — ESP32 не умеет в 5 ГГц), имя комнаты и роль (`master` — один на дом, `slave` — все остальные), по желанию — общий OTA-ключ.
5. Смотрим на роутере/через сканер сети, какой IP получил модуль, открываем `http://<ip>` (у master — панель управления домом, у slave — просто `/ui`, `/status`, `/on`, `/off`, `/toggle`).
6. Переименовать модуль или сменить роль позже — не обязательно переподключаться к точке доступа, достаточно `http://<ip>/config`.

## Обновление прошивки по сети

1. Собрать прошивку (`pio run`), в `src/globals.h` заранее поднять `FIRMWARE_VERSION` — так на `/status` любого модуля всегда видно, какая версия на нём стоит.
2. Зайти на панель мастера (`http://<ip мастера>`), в блоке «Обновление прошивки по сети» загрузить `.pio/build/<env>/firmware.bin`.
3. Нажать «Обновить всю сеть» — мастер сам обойдёт все обнаруженные модули по очереди (и себя — последним, если отмечена галка), подождёт, пока каждый перезагрузится на новой версии, и покажет прогресс.

Важно: этот механизм работает только на модулях, где уже стоит эта прошивка (с поддержкой OTA). Модуль на старой/самой первой прошивке нужно **один раз** обновить по USB — дальше он тоже подключится к общему обновлению по Wi-Fi.

Если задан общий OTA-ключ (поле при настройке модуля), его нужно **одинаково** выставить на всех модулях сети — иначе мастер не сможет их обновить.

## Структура проекта

Прошивка разбита по зонам ответственности вместо одного файла:

- `src/main.cpp` — точка входа, `setup()`/`loop()`
- `src/globals.*` — общее состояние и настройки (WiFi, реле, роль, ключ OTA)
- `src/net_setup.*` — точка доступа для первичной настройки, `/config` для последующей
- `src/relay.*` — управление реле
- `src/discovery.*` — обнаружение модулей по UDP
- `src/ws_events.*` — WebSocket-уведомления о смене состояния
- `src/web_ui.*` — HTTP API и веб-панель (`/status`, `/ui`, `/modules`, `/`)
- `src/ota.*` — OTA: ручное обновление одного модуля и раздача прошивки по всей сети
- `src/health.*` — watchdog и автопереподключение Wi-Fi

## Статус проекта

Рабочий прототип, обкатан на реальной домашней сети из нескольких модулей.
